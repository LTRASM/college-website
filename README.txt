FILES
- index.html : website content and sections
- style.css  : layout, colors, responsive/mobile styling
- script.js  : mobile menu, current year, back-to-top button

HOW TO RUN ON WINDOWS
1. Extract college_website.zip to a folder.
2. Open the folder.
3. Double-click index.html. It should open in your browser.
4. To edit, open index.html and style.css in Visual Studio Code or Notepad.

BEFORE PUBLISHING
- Replace the sample About text with verified college details.
- Add only courses and admission dates confirmed by the college.
- Replace gallery sample tiles with real, approved college photos.
- Add verified address, official phone number, and email.
- Replace sample notices with official announcements.

This is a static starter website. It does not yet have an admin login, database, or form submission backend. The contact section currently displays contact placeholders rather than sending messages.
